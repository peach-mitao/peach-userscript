# 站点规则

[`jav-sites.json`](../jav-sites.json) 是站点与脚本的唯一维护源。构建将同一份清单展开为用户脚本的 `@match`、内联运行规则和 `dist/jav-sites.json` 快照，供 Peach 服务端验证。清单版本 `version: 1` 表示数据结构版本；脚本发布版本见 `package.json`。

当前登记 79 项站点、106 个域名，14 项自动识别、65 项选中番号。基础域名证据见[站点复核](evidence/site-review.json)，DMM / MGS 与镜像的补充证据见[发行平台与镜像复核](evidence/official-and-mirror-review.json)。

| 字段 | 用途 |
| --- | --- |
| `id`、`label`、`kind` | 稳定标识、显示名称、类别 |
| `domains` | 精确登记域名，同时覆盖其子域，仅注入 HTTPS 页面 |
| `mode` | `automatic` 在匹配详情页读取明确身份；`selection` 只接受用户选中的一个短番号 |
| `detail_pattern` | 详情路径正则，第一捕获组可提供番号；数据库站点可只约束路径 |
| `selectors` | 明确标题与番号字段，避免读取推荐区和整页文本 |
| `query_keys` | 允许保留的作品标识参数 |
| `identity` | `peach` 将详情路径第一捕获组或唯一作品参数交给 Peach 编目规则识别；不读取页面 DOM 字段 |

自动规则需匹配详情路径、所需作品参数及明确身份字段。多个不同番号形成冲突，按钮不会查询或提交。用户选定一个完整番号后可以使用菜单明确身份。列表页、搜索页和站内数字 ID 不作为发行番号。

DMM / FANZA 的 `/av/content/?id=…`、旧版数字与 DVD 详情路径，以及 MGS 的 `/product/product_detail/…/` 由 Peach 的只读识别端点处理。脚本只提交净化后的来源地址，Peach 复用编目规则解析商品号；例如 `ssis00519` 识别为 `SSIS-519`，MGS 的三位数字前缀按现有规则保留，Peach 核实过的 SOD 店铺前缀归一为裸番号（`107STZY-019` 识别为 `STZY-019`）。不明确的 DMM 渠道前缀回到手动选择。未配置 Peach 时先显示配置入口。当前 DMM 官方接口已确认示例身份，DMM 与 MGS 详情 DOM 受年龄确认页阻挡，未取得。

新增或变更域名须记录官方迁址、主页链接或可复现页面证据。热门脚本的注入列表只能生成候选，不能独立证明域名归属、站点可达或自动识别规则正确。未取得详情正文且无可独立校验商品号的发行平台规则时使用 `selection`；新增自动规则须补合成页面行为夹具。

浏览器回归会遍历清单中的每个域名，覆盖自动识别或主动选中。既有自动识别夹具按站点 `id` 管理，新增自动站点缺少夹具会失败。清单登记不等于真实扩展与下载联合验收，当前该验收未取得。

MissAV、JavLibrary、JavBus、JAVMost、NJAV / 123AV 和 AVSOX 的补充域名按明确脚本声明或 HTTPS 跳转归属登记。403 挑战只说明探测被限制；JavBus 年龄确认页未提交确认。色花堂的当前首页混淆，采用脚本声明并仅允许主动选中。AirAV 的 `.wiki` / `.fun` 指向 `.io`，AV01 的 `.tv` 指向 `.media`。TLS 错误、连接失败、空白跳转及历史超宽匹配候选保持待核验，不作为脚本注入范围。

JavBooks 的 `jmvbt.com` 与独立站点 `javhd.today` 的 HTTPS 首页标识已核对，均使用选中番号。其余 14 个补充候选存在 TLS / 连接失败、停放页或无关登录页，未登记。所有已登记域名的 `www`、`video` 等子域由同一主域规则覆盖；正则中的任意数字域名和相似域名不批量扩展。
